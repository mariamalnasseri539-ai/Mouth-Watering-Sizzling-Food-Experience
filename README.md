# 🔥 MARIB GRILL & BURGER — Sizzling Gourmet Restaurant Web App

> **مشروع فرونت إند ويب متكامل لمطعم مشويات وبرجر بنكهة بصرية شهية وميزات تفاعلية متقدمة**  
> **A High-Impact, Mouth-Watering Restaurant Experience with Hunger Selector & Customizer**

---

## 🌟 نظرة عامة على المشروع (Project Overview)
**مطعم مأرب للمشويات والبرجر (MARIB GRILL & BURGER)** هو موقع وتطبيق ويب تفاعلي لمطعم وجبات سريعة ومشويات على الحطب، صُمم لإثارة حواس الزائر الجائع بمؤثرات بصرية وصوتية حية تنبض بالحرارة والشهية!

---

## ✨ المميزات التفاعلية المبتكرة (Key Features)

### 1. 🤤 مقياس الجوع التفاعلي (Interactive Hunger Level Selector)
- **جوعان خفيف (Light Snack 🥪):** يفلتر القائمة للأطباق الخفيفة، والبطاطس المقرمشة، والمقبلات.
- **جوعان نص نص (Real Meal 🍔):** يفلتر القائمة للبرجر الكلاسيكي والبيتزا الإيطالية الساخنة.
- **ميت جوع / جوع وحش (Monster Feast 🦁🔥):** يظهر وجبات الكومبو الملكية العملاقة الغرقانة بالجبن واللحم المدخن لمواجهة أقوى لحظات الجوع!

### 2. 🍔 مخصص الوجبات والإضافات (Live Food Customizer & Toppings)
- إمكانية الضغط على أي وجبة لتخصيص الإضافات:
  - 🧀 شلال جبنة شيدر إضافية ذائبة (+ $1.50)
  - 🥓 شرائح بيكون بقري مقرمش مدخن (+ $2.00)
  - 🌶️ هالبينو حار مكرمل (+ $1.00)
  - 🍯 صوص باربيكيو بالترفل السري (+ $1.00)
- حساب فوري وديناميكي للسعر الإجمالي وإضافته لسلة الطلبات.

### 3. 💡 إضاءات الجمر والأنيميشن الحركي (Glow & Food Floating Animations)
- **وضع الجمر الليلي (Gourmet Charcoal Dark Mode):** تدرجات فحمية داكنة مع إضاءات لهيب ونيران برتقالية وذهبية تسلب الأنظار.
- **الوضع النهاري (Fresh Morning Diner Mode):** مظهر مشرق وعاجي ناصع.
- **حركة الأطعمة العائمة (Food Float Keyframes):** صور أطباق البرجر والبيتزا تطفو وتتحرك بانسيابية ثلاثية الأبعاد خفيفة.

### 4. 🛒 سلة طلبات فورية وربط مباشر بالواتساب (Cart & WhatsApp Integration)
- عداد حي للطلبات في القائمة العلوية.
- نافذة منبثقة للسلة مع خيارات تعديل الكميات وحساب الإجمالي.
- زر **"إرسال الطلب عبر واتساب"** لتجهيز رسالة الطلب شاملة الوجبات والإضافات المخصصة وتوجيهها مباشرة لرقم المطعم.

### 5. 📅 نظام حجز طاولات تفاعلي (Table Booking Modal)
- حجز مسبق للطاولات والجلسات العائلية وقسم الـ VIP مع تنبيهات Toast Notification أنيقة.

### 6. 🌐 دعم كامل للعربية والإنجليزية (Bilingual RTL / LTR)
- تبديل فوري بين العربية والإنجليزية مع ضبط كامل لاتجاه الصفحة وتخزين التفضيل في `localStorage`.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **HTML5** | هيكل دلالي مهيأ للـ SEO وسهولة الوصول (Accessibility) |
| **CSS3** | متغيرات الألوان، تأثيرات الإضاءة واللهيب، Glassmorphism، وأنيميشن Float |
| **Vanilla JavaScript (ES6+)** | محرك مقياس الجوع، مخصص الإضافات، السلة، وإدارة اللغات والثيم |
| **Font Awesome 6** | أيقونات عصرية متوافقة مع كافة الشاشات |

## 🚀 طريقة التشغيل (How to Run)
افتح ملف `index.html` في أي متصفح ويب حديث (Chrome أو Edge أو Firefox) واستمتع بالتجربة التفاعلية!
